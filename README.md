# Prism Crush — Shatter the Crystal Depths

**在线体验 / Play online:** https://pipygames.com/games/prism-crush-shatter-the-crystal-depths-mghd

Prism Crush is a classic falling-block puzzle rebuilt as a hand-painted crystal cavern. Same 13×20 board, same ten non-standard gem shapes, same arrows-only controls — but every settled block sits in a chiselled socket, and the cavern repaints itself as you mine deeper through four glowing strata. Clear rows to shatter them, chain 1-to-4 line scores, and chase your own best score. Free in your browser, no download.
